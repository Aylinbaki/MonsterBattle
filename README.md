🐉 MonsterBattle

📌 About the Project
MonsterBattle is a Java-based project developed as part of the Data Structures and Algorithms course.
The project implements fundamental data structures and applies them in a simple monster battle game. 
Players use their monsters to fight against each other, and the system manages battles, levels, and game-ending conditions using custom data structures.

🎮 Features
Monster Management: Add, remove, and search monsters.
Battle System: Players select monsters to engage in battles.
Leveling Up: Winning monsters gain levels.
Game End Conditions:
  A player loses all their monsters, or
  A player wins 3 consecutive battles.

🗂️ Project Structure
Monster.java → Defines the Monster class
Player.java → Defines the Player class
Game.java → Controls the game flow and rules
MyHashMap.java → Custom hash table implementation for storing monsters

📚 Notes
This project was created as part of the Data Structures and Algorithms course.
The aim is to practice hash tables, tree-based data structures, object-oriented programming, and algorithm design.

🛠️ Requirements
Java 8 or later
